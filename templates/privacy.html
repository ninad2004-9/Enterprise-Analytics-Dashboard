Privacy Policy

Last updated: October 2026

1. Information We Collect

This demo application allows users to register an account to test authenticated dashboard sessions. We only store:

  • Display name or username chosen by the user
  • Email address (for demonstration login identifiers only)
  • Cryptographically salted password hash (we never store plain-text passwords)
  • Uploaded sample dataset files, processed entirely in-memory or session storage during your browser session

2. How Information is Used

Information entered into this application is used solely to authenticate your demonstration session and render interactive analytical charts. We do not sell, rent, commercialize, or share your data with any third-party advertisers or data brokers.

3. Data Retention & Security

Account records are held in a local SQLite database for test session management. Uploaded CSV/Excel files are processed in-memory during user sessions. Since this is a public demonstration project, users are advised not to enter real-world proprietary passwords or private business records.

4. Open Source & Contact

For questions or source code review, please contact the project repository maintainer or visit the homepage.
