Frequently Asked Questions

Everything you need to know

Common technical questions regarding deployment, security, and data formats.

How does the 1-Click Instant Demo work?
Clicking the "1-Click Demo" button immediately establishes an authenticated session under a pre-seeded demonstration profile. You get instant access to the entire interactive dashboard and sample datasets without having to create or register personal credentials.
What dataset formats does DataSphere support?
DataSphere natively supports CSV files, modern Excel workbooks (.xlsx), legacy Excel workbooks (.xls), and structured SQLite queries. The ingestion engine automatically identifies column types, handles missing data, and casts numerical columns into vectorized NumPy/Pandas arrays.
Is my uploaded business data private?
Yes. DataSphere maintains a strict privacy-first architecture. Uploaded data is analyzed inside your isolated web session and is never sold, shared, or fed into third-party AI training pipelines. For complete details, review our Privacy Policy.
Can I run DataSphere locally on my own machine?
Absolutely. DataSphere is 100% open-source Python. You can clone the GitHub repository, install the dependencies with pip install -r requirements.txt, and launch it locally with python app.py for an entirely offline air-gapped analytics environment.
